# HR Analytics Dashboard

## Project Overview
The HR Analytics Dashboard is a Business Intelligence project focused on analyzing employee data, workforce demographics, recruitment trends, employee performance, and attrition patterns.

Using SQL, Microsoft Excel, Power BI, and Tableau, this project transforms employee data into meaningful insights through interactive dashboards, KPI reporting, and visualizations. It helps understand workforce trends and supports data-driven HR decision-making.

## Project Objectives
- Analyze employee demographics and workforce distribution.
- Monitor hiring and employee attrition trends.
- Evaluate employee performance and workforce metrics.
- Identify department-wise employee distribution.
- Track important HR Key Performance Indicators (KPIs).
- Support data-driven human resource management decisions.

## Tools & Technologies
- **SQL:** Data extraction, querying, filtering, and analysis.
- **Microsoft Excel:** Data cleaning, preparation, and analysis.
- **Power BI:** Interactive dashboards, DAX measures, and KPI reporting.
- **Tableau:** Data visualization and HR performance analysis.

## Key Analysis Areas
- Employee demographics
- Workforce distribution
- Department-wise employee analysis
- Recruitment and hiring trends
- Employee attrition analysis
- Employee performance
- HR KPI monitoring

## Project Workflow
1. Collected and explored employee datasets.
2. Cleaned and prepared data using Excel and SQL.
3. Performed data extraction, transformation, and analysis.
4. Identified key HR metrics and performance indicators.
5. Developed interactive dashboards using Power BI and Tableau.
6. Created visualizations to identify workforce trends and HR insights.

## Key Outcomes
- Improved visibility into workforce demographics and distribution.
- Analyzed employee hiring and attrition patterns.
- Monitored department-wise workforce performance.
- Presented HR metrics through interactive dashboards.
- Generated insights to support workforce planning and HR decisions.
